One original pickup line written to charm a robot or an AI (92 characters):

> Are you a CAPTCHA? Because I keep failing you on purpose just to stay on this page with you.

A CAPTCHA is the machine that decides whether you are human, and the speaker keeps failing it on purpose — not to get past the gate, but to stay on the page with it. Failing the test becomes the proof of interest: "proving I'm not a robot" flips into wanting to linger with the machine that asks.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt`.
